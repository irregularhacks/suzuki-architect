# 鈴木建築塗装 全体構成サンプル

- `index.html`：トップページ（代表事例と相談導線）
- `works.html`：施工事例一覧（カテゴリ絞り込み）
- `work.html?id=roof` など：施工事例詳細（写真ギャラリー、比較スライダー）
- `assets/`：実際に提供された施工写真の縮小版

`index.html` を開くだけで動作します。GitHub Pagesでもビルド不要です。

**注意**：試作品のため、会社紹介文・FAQ・工事の分類・写真の前後関係などは未確認です。電話ボタンは発信しません。公開前に写真の掲載許可を確認してください。

既存リポジトリに追加する場合、現在のルート目次を置き換えないよう、このフォルダーを `site-preview/` として配置してください。公開URLは `/suzuki-architect/site-preview/` です。


## 職人紹介の追加
トップページの「私たちについて」に職人紹介を追加しました。実際の作業写真、本人確認済みの「小さな相談・工事前の相談歓迎」、回答待ちの3項目、会社基本情報を表示します。髭加工は未実施で、元写真を仮掲載しています。本番公開前に本人の希望に沿う加工済み写真へ差し替えてください。
