# 鈴木塗装建築 HP 機能サンプル集

GitHub Pagesで公開できる静的HTML一式です。`index.html` が目次です。

## 収録内容
- `before-after/` 施工前後の比較スライダー
- `markers/` 写真マーカー比較（工程ストーリーは非表示）
- `process/` 工程ストーリー（マーカーは非表示）
- `faq/` 人物イラストを使った会話FAQ（スマホ表示の人物を拡大）

## 公開方法
1. **このフォルダーの中身**（`index.html` と各フォルダー）をGitHubリポジトリのルートに追加してコミット・push。
2. GitHubの **Settings → Pages → Build and deployment → Deploy from a branch** を選択。
3. Branchを `main`、Folderを `/(root)` にして保存。
4. 公開URL `https://<ユーザー名>.github.io/<リポジトリ名>/` を開く。

外部ライブラリやビルド処理は不要です。すべて相対パスです。

## 注意
- **実際の施工写真を含みます。公開リポジトリやGitHub Pagesに載せる前に、写真の掲載許可と個人情報・住所・表札等の映り込みを確認してください。**
- FAQの回答文・施工工程の順番は仮の内容を含みます。実際の案内と混同しないでください。
- FAQ人物の向き・画風の統一は未完成です。今回は動作確認用です。
- 現段階では画像はHTMLに埋め込み済みのため、ファイル単体で動きます。編集・更新しやすい構造への変更は本番制作時に検討します。
